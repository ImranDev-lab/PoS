# Database Schema (SQLAlchemy 2.0)

## ERD (Mermaid)
```mermaid
erDiagram
    Users ||--o{ Invoices : creates
    Products ||--o{ InvoiceItems : "sold in"
    Products ||--o{ AIStockPredictions : "predicted for"
    Invoices ||--||{ InvoiceItems : contains
    Invoices ||--o{ OfflineSyncQueue : "queued for"
    AILog }o--|| Users : "by"

    Users {
        uuid id PK
        string username UK
        string email UK
        string password_hash
        enum role
        boolean is_active
        datetime created_at
    }

    Products {
        uuid id PK
        string sku UK
        string name
        string barcode UK
        string unit
        decimal cost_price
        decimal selling_price
        decimal tax_rate
        decimal stock_quantity
        decimal reorder_level
        decimal low_stock_threshold
        boolean is_active
    }

    Invoices {
        uuid id PK
        string invoice_number UK
        string customer_name
        string customer_phone
        string currency
        decimal subtotal
        decimal tax_amount
        decimal discount_amount
        decimal total_amount
        enum payment_status
        enum status
        datetime created_at
        boolean is_synced
        string local_id
    }

    InvoiceItems {
        uuid id PK
        uuid invoice_id FK
        uuid product_id FK
        decimal quantity
        decimal unit_price
        decimal tax_amount
        decimal line_total
    }

    AIStockPredictions {
        uuid id PK
        uuid product_id FK
        datetime predicted_stock_out_date
        int days_until_stockout
        decimal recommended_reorder_quantity
    }

    AILog {
        uuid id PK
        string action_type
        text input_data
        text output_data
        datetime created_at
    }

    OfflineSyncQueue {
        uuid id PK
        string table_name
        string record_id
        string operation
        text payload
        enum status
    }
```

## Core Tables
See `pos-system/backend/app/models.py` for the executable SQLAlchemy models. Key entities:

- **Users** — cashier / manager / admin with bcrypt password hashes.
- **Products** — SKU, barcode, unit (pcs/kg/L), cost & selling price, tax rate, stock quantity, reorder level, low-stock threshold.
- **Invoices** — header with subtotal, tax, discount, total, payment status, currency (PKR/USD/etc.), sync flags for offline mode.
- **InvoiceItems** — line items linked to product; stock is auto-decremented on invoice creation.
- **AIStockPredictions** — proactive reorder warnings generated by the AI stock service.
- **AILog** — audit trail for voice-to-bill, OCR, and prediction actions.
- **OfflineSyncQueue** — outbox pattern for PWA/desktop offline sync.

## Running Migrations
For production, add Alembic:
```bash
cd backend
pip install alembic
alembic init alembic
# edit alembic.ini with DATABASE_URL, then:
alembic revision --autogenerate -m "init"
alembic upgrade head
```
In development, `Base.metadata.create_all` runs on startup.
